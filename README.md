# Eesti A2 — тренажёр форм + шпаргалка

Статичная PWA без фреймворков и без бэкенда. Работает офлайн, прогресс — в
localStorage браузера/телефона.

## Запуск локально

```bash
python -m http.server 8130 --directory eesti
```

Открыть http://localhost:8130. В Claude Code — просто preview `eesti`
(конфиг уже в `.claude/launch.json`).

Через `file://` не работает: service worker и `fetch` файлов требуют http.

## Что внутри

| Вкладка | Что делает |
|---|---|
| **Формы** | Даёт `nimetav` / `ma`-инфинитив, ты вводишь остальные основные формы. У глагола — ещё и основу отрицания (`ei loe`). Главный режим. |
| **Слова** | RU → ET (ввод) и ET → RU (самооценка «знал / не знал»). |
| **Микс** | Всё вперемешку. |
| **Шпаргалка** | Отрицание, вопросы, порядок слов, падеж объекта, императив, рекция. Только чтение. |

Кнопки `õ ä ö ü š ž` под карточкой — с русской раскладки иначе не набрать.
Enter переходит к следующему полю, на последнем — проверяет.

## Как добавлять слова

**Формы руками не пишем.** Они приходят из EKI (`api.sonapi.ee`, витрина
Sõnaveeb) через `tools/sonaveeb.py`. Наше дело — начальная форма и перевод.

Файл со словами, по строке на слово:

```
helistama — звонить — helistan
vann — ванна — vann
```

Третья колонка — форма, как она напечатана в учебнике. Она нужна затем, что
книга даёт слова в личной форме (`helistan`), а словарь понимает только
начальную (`helistama`). Начальную подбирает человек — и скрипт тут же
проверяет: если книжной формы нет среди форм словарной статьи, строка уходит
в отчёт, а не в словарь. Колонку можно опустить, тогда проверки не будет.

```bash
python tools/sonaveeb.py add words-new.txt
```

Остальные команды:

| Команда | Что делает |
|---|---|
| `check` | Сверяет весь `words.json` с EKI. Молчит, если всё сошлось. |
| `fix` | Переписывает формы по словарю, дозаполняет отрицание, прошедшее, nud-форму и рекцию. |
| `show lugema` | Показывает, что словарь знает про слово. |

Ответы кэшируются в `tools/.cache/` (в git не идёт), при 429 скрипт
отступает и повторяет.

## Слова из учебника

`tools/book.py` разбирает «Eesti keele sõnavihik A2» на поурочные списки:

```bash
python tools/book.py list sonavihik.pdf
python tools/book.py dump sonavihik.pdf 12.1
```

**Сам PDF в репозиторий не кладём** — учебник под копирайтом
Kultuuriministeerium. Скрипт работает с локальной копией, в git едут только
слова и наши переводы.

У восьми уроков (3.4, 4.4, 7.5, 13.2, 14.2, 15.2, 21.4, 23.2) списки
нарисованы картинками — оттуда текст не извлекается, эти уроки заводятся
вручную.

Многословные выражения (`pesen hambaid`, `akna all`) в карточки форм не
годятся — их место в шпаргалке `data/grammar.json`, структура
`sections[].rows[]` с полями `et` / `ru` / `hint`.

Через запятую в поле формы — равноправные варианты из словаря
(`tube,tubasid`), тренажёр примет любой.

## Алгоритм повторений

SM-2 lite. Ответил верно → интервал 1 → 3 → ×ease (ease растёт до 2.8).
Ошибся → интервал в ноль, ease −0.2, карточка возвращается через три позиции
в этой же сессии. Лимит новых карточек в день — в настройках, по умолчанию 12.

## Деплой

Cloudflare Pages: подключить папку как проект без билд-команды
(`Build output directory` = корень). Домен → на iPhone открыть в Safari →
«Поделиться» → «На экран Домой». Так iOS не выкидывает localStorage
и приложение открывается офлайн.

**После правки файлов подними `CACHE` в `sw.js`**, иначе на телефоне
останется закэшированная старая версия. `data/*.json` кэшируется
network-first — словарь доезжает без смены версии.

## Бэкап прогресса

Настройки → «Выгрузить прогресс» / «Загрузить прогресс». Перед сменой
устройства или чисткой Safari — обязательно.
